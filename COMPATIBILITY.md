# Game compatibility

This page collects community testing results for PrizmGBC on the Casio fx-CG50.

Compatibility can vary by game revision, calculator OS and PrizmGBC build. A report is an observation, not a guarantee that every copy or setup will behave identically.

## Submit a report

Use the [Game compatibility report](https://github.com/Jzx12348/PrizmGBC/issues/new?template=compatibility_report.yml) issue form.

Include the game title, region/revision, PrizmGBC version, calculator model, OS version and what you tested. Do not upload, link to or distribute ROM files.

## Status definitions

| Status | Meaning |
| --- | --- |
| Playable | Tested beyond startup and reported playable for the stated test conditions. |
| Playable with issues | Gameplay works, but one or more noticeable issues were observed. |
| In-game but major issues | The game reaches gameplay, but major problems limit use. |
| Does not boot | The game did not reach gameplay in the reported test. |
| Crashes / freezes | The emulator or game stopped responding during the reported test. |
| Untested | No usable test report is available. |

## Verification notes

- Community-submitted results should identify the exact PrizmGBC build tested.
- A result should not be marked verified based only on a game reaching its title screen.
- Where practical, test gameplay, graphics, audio, controls and save behaviour separately.
- Conflicting reports should remain documented with their different test conditions.
- Never share copyrighted ROMs or private save data to support a report.
