WHAT COMES NEXT / PROJECT ROADMAP

BUILT IN
CHAPTERS.

PrizmGBC will evolve in stages. Each release builds on the last, with v2.0.0 planned as a major overhaul of the emulator and the complete application experience.

NEXT / v1.3.0

Library & usability

Make browsing, managing and returning to games feel more complete.

  • Complete game library redesign
  • Grid and list view options
  • Individual game information screens
  • Per-game settings profiles
  • Improved recently played and playtime tracking
  • Dedicated save-state management
FOLLOWING / v1.4.0

Personalisation

Give players more control over how PrizmGBC looks and behaves.

  • Custom themes and accent colours
  • Configurable game controls
  • Quick Resume
  • Save-state previews, if practical
  • More sorting and filtering options
  • Expanded performance statistics
MAJOR RELEASE / v2.0.0

The next generation

A substantial evolution of the emulator, interface and overall experience.

  • Emulator engine: performance, compatibility, timing, graphics and audio improvements
  • Interface: complete UI overhaul, redesigned library, game pages and menus
  • Game management: artwork, metadata, profiles and advanced save management
  • Configuration: expanded display, audio, controls and diagnostics
  • Personalisation: themes and configurable interface options
  • Reliability: compatibility testing, migration, stability and memory improvements

Roadmap note: These are planned directions, not guaranteed features or release dates. Scope will be refined as development progresses and tested against the fx-CG50's hardware, memory and SDK limitations. The existing PrizmGBC logo and application icon will remain unchanged.
