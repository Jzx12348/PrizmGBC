PrizmGBC brings Game Boy and Game Boy Color games to the Casio fx-CG50, with a focused library, configurable controls and calculator-native installation.

01 / LIBRARY

Grid or list

Choose the library layout that works best and keep that preference between sessions.

02 / DISCOVERY

Game details

Open individual game pages to inspect ROM title, cartridge type, file size and memory information.

03 / COLLECTION

Favourites & recents

Keep favourites close, revisit recently played games and sort the library by activity.

04 / PROFILES

Per-game settings

Save and manually apply performance, display, audio and control profiles for individual games.

05 / PLAYTIME

Playtime tracking

Track time per game and sort your library by accumulated playtime.

06 / SAVE STATES

Three save slots

Manage three save-state slots. F3 saves and F4 loads the selected slot.

07 / CONTROLS

Function-key hints

Library actions are labelled above their matching F1, F2, F3, F4, F5 and F6 calculator keys.

08 / SETTINGS

Organised settings

Five settings categories cover performance, display, controls, audio and system options.

09 / DISPLAY

Flexible display

Choose native 1×, 1.5× Fit or 2× Crop display modes and tune the emulator experience.

GETTING STARTED / FX-CG50

THREE STEPS
TO PLAY.

The stable build is distributed as a standard Casio add-in. You supply your own legally obtained game ROMs.

STEP 01

Download

Get PrizmGBC.g3a from the latest stable release. The current stable version is v1.3.1.

OPEN STABLE RELEASE ↗
STEP 02

Transfer

Connect the fx-CG50, copy the .g3a file and your compatible .gb or .gbc ROM files to calculator storage, then safely eject.

STEP 03

Launch

Open PrizmGBC from the calculator's add-in menu, select a game and start playing. F3 and F4 handle save states.

PrizmGBC does not include commercial game ROMs. Use only game files you are legally entitled to use.

WHAT COMES NEXT / PROJECT ROADMAP

BUILT IN
CHAPTERS.

PrizmGBC will evolve in stages. Each release builds on the last, with v2.0.0 planned as a major overhaul of the emulator and the complete application experience.

RELEASED / v1.3.0

Library & usability

Make browsing, managing and returning to games feel more complete.

  • Released: Persistent grid and list layouts
  • Released: Individual game information screens
  • Released: Per-game settings profiles
  • Released: Playtime tracking and playtime sorting
  • Released: Dedicated three-slot save-state manager
  • Included: Function-key footer labels and improved settings tab spacing
FOLLOWING / v1.4.0

Personalisation

Give players more control over how PrizmGBC looks and behaves.

  • Custom themes and accent colours
  • Configurable game controls
  • Quick Resume
  • Save-state previews, if practical
  • More sorting and filtering options
  • Expanded performance statistics
MAJOR RELEASE / v2.0.0

The next generation

A substantial evolution of the emulator, interface and overall experience.

  • Emulator engine: performance, compatibility, timing, graphics and audio improvements
  • Interface: complete UI overhaul, redesigned library, game pages and menus
  • Game management: artwork, metadata, profiles and advanced save management
  • Configuration: expanded display, audio, controls and diagnostics
  • Personalisation: themes and configurable interface options
  • Reliability: compatibility testing, migration, stability and memory improvements

Roadmap note: These are planned directions, not guaranteed features or release dates. v1.3.1 is the current stable baseline, building on v1.3.0. Future features will be developed against the fx-CG50 hardware, memory and SDK limits. The existing PrizmGBC logo and application icon will remain unchanged.
