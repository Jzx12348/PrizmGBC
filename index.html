01 / THE PROJECT

SMALL DEVICE.
BIG NOSTALGIA.

PrizmGBC is an open-source experiment built around the idea that classic handheld games belong in unexpected places.

01 / FORMATS

Two generations.

Designed around original Game Boy (.gb) and Game Boy Color (.gbc) ROM files, with compressed .gbz support inherited from its upstream base.

02 / PLATFORM

One calculator.

Targeting the Casio Prizm fx-CG50 family, with device testing and compatibility work still in progress.

03 / OPEN SOURCE

Built in public.

Source code, build notes, and development progress live on GitHub. Contributions and careful testing help move the project forward.

PRIZMGBC / FIELD NOTES

NOT A FINISHED PRODUCT.
YET.

This is an experimental emulator fork. Compatibility, speed, and display output are being actively investigated. No claim of full-game compatibility is made.
