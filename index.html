One small calculator. Two generations of handheld gaming. A very different place to play.

PrizmGBC is an experimental Game Boy and Game Boy Color emulator for the Casio fx-CG50.

01 / Compatibility first

CPU behaviour, memory banking, graphics timing and cartridge support all matter. A boot screen is not a compatibility claim.

02 / Performance matters

Every frame has a cost. Rendering and emulation need to work together within the fx-CG50 hardware budget.

03 / Open development

Builds, source changes and known issues stay visible. Hardware testing is part of the engineering process.
