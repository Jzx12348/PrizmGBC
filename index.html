WHAT’S NEW IN
VERSION 1.1.0.

The latest stable update adds practical quality-of-life improvements to the library, controls and rendering experience.

01 / LIBRARY

Game favourites

Mark and unmark favourite games directly from the library for quicker access to your collection.

02 / CONTROLS

Individual remapping

Change calculator key bindings one at a time instead of having to remap every control.

03 / CONTROLS

Reset to defaults

Restore the original key layout with a dedicated reset action.

04 / PERFORMANCE

In-game FPS counter

See the current frame rate while playing, with an option to turn the counter on or off in settings.

05 / RENDERING

Optimised scaling

Improved 1.5× and 2× framebuffer scaling paths reduce work in the pixel rendering loops.

06 / INTERFACE

Visual refinements

A refreshed green accent palette and refinements across the game library and settings screens.
